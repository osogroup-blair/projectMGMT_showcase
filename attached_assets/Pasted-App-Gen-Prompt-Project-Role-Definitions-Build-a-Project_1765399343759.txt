App Gen Prompt – Project Role Definitions

Build a “Project Role Definitions” page at route /projects/:projectId/roles.
This page manages the set of roles available for the project.
Load current project roles and optional role templates.
Each role has: name, description, role_type (e.g., Core, Delivery, Finance), is_required, max_assignees, and a permissions JSON.
Allow creating, editing, and deleting roles, and optionally seeding from a template.
Use the JSON view schema provided.
