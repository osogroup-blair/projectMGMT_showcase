App Gen Prompt – Stage View Settings

Build a “Stage View Settings” page at route /projects/:projectId/stages/:stageId/view-settings.
Load the stage and its view configuration.
Let the user choose view type (Kanban, Table, Timeline, etc.), visible fields, default sort, default filters, and metrics.
Include actions to save the view config for the stage, and to save a personal view.
Use the JSON view schema provided.
