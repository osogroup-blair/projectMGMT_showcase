Project Team & Roles Overview
App Gen Prompt – Project Team & Roles Overview

Build a “Project Team & Roles Overview” page at route /projects/:projectId/team.
This page summarizes who is on the project and what roles they have.
Load project roles, role assignments, and users.
Show:

A table grouped by role: each row shows role name, description, required/optional, # of assignees, and list of assigned people.

Optionally, a secondary view by person: each person and the roles they hold on this project.
Add actions:

“Manage Role Definitions” → /projects/{projectId}/roles

For each role: “Assign People” → /projects/{projectId}/roles/{roleId}/assignments
Use the JSON view schema provided for data sources, entities, and actions.
