App Gen Prompt – Project Import: Preview & Confirm

Build a “Project Import – Preview & Confirm” page at route /projects/import/:sessionId/preview.
Show a summary of what will be created/updated/ignored plus a paginated grid of preview rows with their status (new, update, ignored, error).
Allow filtering by row status.
Include actions to go back to mapping, and to “Import & Apply” which runs the import and then routes to the project overview.
Use the JSON view schema provided.
