App Gen Prompt – Project Import: Field Mapping

Build a “Project Import – Field Mapping” page at route /projects/import/:sessionId/mapping.
Load the import session, the file columns, and the list of system fields.
Let the user map each file column to a system field and optionally save that mapping as a reusable template.
Include buttons to “Save Mapping”, “Save as Template”, and “Continue to Preview” which navigates to /projects/import/{sessionId}/preview.
Use the JSON view schema provided.
