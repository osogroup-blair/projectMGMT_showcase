App Gen Prompt – Task Board

Build a “Task Board” page at route /projects/:projectId/tasks.
The page should show project tasks in a board-style view (e.g., grouped by stage or status) with filters and actions.
Load tasks, stages, milestones, and saved views for this project.
Filters: stage, status, assignee, milestone, and saved view.
Each task should include title, description (optional), stage, status, assignee, due date, priority, milestone, estimate hours, and tags.
Actions: create task, update task, move task between stages, bulk update tasks, and open task detail at /projects/{projectId}/tasks/{taskId}.
Use the JSON view schema provided to wire up data, filters, and actions.
