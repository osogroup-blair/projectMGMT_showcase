App Gen Prompt – Project Import: File Upload

Build a “Project Import – File Upload” page at route /projects/import.
The user should choose whether to create a new project or attach to an existing project, select an existing active project when needed, and upload a file to start an import session.
After creating the import session, navigate to /projects/import/{sessionId}/mapping.
Use the JSON view schema provided for data and actions.
