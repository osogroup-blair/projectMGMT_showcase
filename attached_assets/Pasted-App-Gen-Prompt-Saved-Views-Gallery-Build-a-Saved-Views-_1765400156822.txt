App Gen Prompt – Saved Views Gallery

Build a “Saved Views Gallery” page at route /projects/:projectId/views.
Show a list of saved views for this project with name, description, stages covered, view type, visibility (global/personal), default flag, and underlying config.
Allow filtering by view type and visibility.
Actions: create view (navigate to /projects/{projectId}/views/new), edit view (/projects/{projectId}/views/{viewId}), set default view, and delete view.
